# 距离计算改进与参数合并

> 更新日期: 2026-03-14

## 1. 距离计算：从累计路径改为首点最大偏离

### 问题

之前手势识别中判断"手指是否静止"使用的是**累计路径长度**（相邻采样点距离之和）。
这种方式在手指原地抖动时会严重失真：

```
坐标序列: 0 → 1 → 0
累计路径长度 = 1 + 1 = 2   ← 被放大
实际偏移 = max(1, 0) = 1   ← 真实
```

4 指 tap 测试中，有 3/13 次因抖动累加导致 `MaxPerFingerDistance` 超过阈值（46px > 30px），被误判为 Trajectory。

### 修复

改为**首点最大偏离距离**：计算轨迹中每个点到首点（down 位置）的距离，取最大值。

受影响文件：
- `GestureSign.Daemon/Input/GestureAnalyzer.cs` — `Analyze()` 中每根手指距离计算
- `GestureSign.Daemon/Input/TipTapMath.cs` — `GetTrajectoryDistance()`

两处使用相同逻辑：
```csharp
var origin = trajectory[0];
double maxDeviation = 0;
for (int i = 1; i < trajectory.Count; i++)
{
    double d = PointPatternMath.GetDistance(origin, trajectory[i]);
    if (d > maxDeviation)
        maxDeviation = d;
}
```

## 2. 参数合并对照表

### 2.1 合并前状态

同一概念在多处重复定义：

| 概念 | 重复位置 | 旧定义方式 |
|------|---------|-----------|
| Tap 移动阈值 18px | GestureAnalyzer (const)、GestureClassifier (魔法数字 ×4)、ContactGestureConfig (魔法数字) | 各自硬编码 |
| Tap 最大时长 300ms | GestureAnalyzer (const)、GestureClassifier (魔法数字) | 各自硬编码 |
| Click 最大时长 600ms | GestureClassifier (魔法数字) | 硬编码 |
| TipTap 方向死区 24px | GestureClassifier (魔法数字 ×4) | 硬编码 |
| TipTap 重复冷却 60ms | GestureClassifier (魔法数字 ×2) | 硬编码 |
| TipTap Fix 稳定阈值 12px | GestureClassifier (魔法数字 ×2) | 硬编码 |

### 2.2 合并后

| 概念 | 权威来源 | 引用方式 |
|------|---------|---------|
| Tap 移动阈值 18px | `TapGestureRecognition.DefaultMaxMovementPx` | const |
| Tap 最大时长 300ms | `TapGestureRecognition.DefaultMaxDurationMs` / `AppConfig.TapMaxDurationMs` | const + 可配置 |
| Click 最大按压时长 600ms | `ClickGestureRecognition.DefaultMaxPressDurationMs` | const |
| Click 移动阈值 18px | `ClickGestureRecognition.DefaultMaxMovementPx` | const |
| TipTap 方向死区 24px | `TipTapRecognition.DefaultDirectionDeadzonePx` | const |
| TipTap 重复冷却 60ms | `TipTapRecognition.DefaultRepeatCooldownMs` | const |
| TipTap Fix 稳定阈值 12px | `TipTapRecognition.DefaultFixStillThresholdPx` | const |
| TipTap Tap 移动阈值 18px | `TipTapRecognition.DefaultTapMaxMovementPx` | const |
| TipTap Tap 硬上限 220ms | `GestureClassifier.TipTapTapHardLimitMs` | private const |
| TipTap 最小最大时长 140ms | `GestureClassifier.TipTapMinMaxDurationMs` | private const |

### 2.3 GestureAnalyzer 参数改为 AppConfig

| 参数 | 旧来源 | 新来源 |
|------|-------|-------|
| TapMaxDurationMs | 硬编码 300 | `AppConfig.TapMaxDurationMs`（默认 300） |
| TapRelaxedOutlierMovementPx | 硬编码 30 | `AppConfig.TapDistanceThreshold`（默认 30） |
| TapStrictMovementPx | 硬编码 18 | 保留 const（严格快路径，不需要用户调） |
| TapRelaxedMajorityMovementPx | 硬编码 20 | 保留 const（= Strict + 2，内部逻辑） |

## 3. 当前全部手势参数清单

### AppConfig 可配置参数（Options UI）

| 参数 | 默认值 | UI Slider 范围 | 用途 |
|------|--------|---------------|------|
| TapDistanceThreshold | 30 px | 10-100, 步长 5 | Tap/TipTap 宽松距离阈值 |
| TapMaxDurationMs | 300 ms | 100-500, 步长 10 | Tap 最大持续时间 |
| TipTapMaxTapDurationMs | 150 ms | 50-300, 步长 10 | TipTap 点击指超时 |
| TipTapFixMinHoldMs | 50 ms | 0-200, 步长 10 | TipTap 固定指最小保持时间 |
| MinimumPointDistance | 20 px | 3-100 | 轨迹手势最小采样点距离 |
| GestureMatchProbability | 80% | 50-95 | 轨迹手势匹配概率阈值 |

### ContactGestureConfig 每定义级参数

这些参数存储在每个手势定义中，录制时根据实际观测值自动设置：

| 类 | 参数 | 默认值 | 用途 |
|---|------|--------|------|
| TapGestureRecognition | MaxDurationMs | 300 | 单次 Tap 最大时长 |
| TapGestureRecognition | MaxMovementPx | 18 | Tap 最大移动量 |
| TapGestureRecognition | MinFingerCount | 2 | 最少手指数 |
| ClickGestureRecognition | MaxPressDurationMs | 600 | Click 最大按压时长 |
| ClickGestureRecognition | MaxMovementPx | 18 | Click 最大移动量 |
| ClickGestureRecognition | MinFingerCount | 2 | 最少手指数 |
| TipTapRecognition | FixMinHoldMs | AppConfig | 固定指最小保持时间 |
| TipTapRecognition | MaxTapDurationMs | AppConfig | 点击指超时 |
| TipTapRecognition | FixStillThresholdPx | 12 | 固定指静止判定 |
| TipTapRecognition | TapMaxMovementPx | 18 | 点击指移动判定 |
| TipTapRecognition | DirectionDeadzonePx | 24 | 方向判定死区 |
| TipTapRecognition | RepeatCooldownMs | 60 | 重复手势冷却 |

### 内部常量（不可配置）

| 位置 | 常量 | 值 | 用途 |
|------|------|-----|------|
| GestureAnalyzer | TapStrictMovementPx | 18 | 严格快路径：所有手指移动 < 18px 直接判定为 Tap |
| GestureAnalyzer | TapRelaxedMajorityMovementPx | 20 | 宽松路径：多数手指移动 ≤ 20px |
| GestureClassifier | TipTapTapHardLimitMs | 220 | TipTap 点击指时长硬上限 |
| GestureClassifier | TipTapMinMaxDurationMs | 140 | TipTap 最小最大时长基数 |

- **新增** TapMaxDuration Slider (100-500ms, 步长 10)

- **更新** TapDistanceThreshold 描述：从"总移动距离"改为"手指离起始点的最大偏移距离"

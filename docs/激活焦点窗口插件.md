# "激活焦点窗口" 插件

> **项目**: GestureSign
> **功能**: 在手势起始位置模拟点击以激活窗口
> **日期**: 2026-02-13

---

## 需求背景

用户在通达信等应用中配置手势动作链：先模拟鼠标左键点击激活窗口，再发送快捷键（如 Shift+F8）。

**问题**：触摸屏场景下，鼠标光标位置与手指实际触控位置不一致。现有的"鼠标动作 → 当前位置单击左键"使用的是鼠标光标位置，而非手指触控位置，导致点击无法激活正确的窗口。

**解决方案**：新建专用插件，自动根据输入设备类型在正确位置模拟点击。

---

## 技术方案

### 核心原理

`PointInfo.PointLocation[0]` 在不同设备下已自动包含正确坐标：

| 输入设备 | `PointLocation[0]` 的值 | 来源 |
|---------|------------------------|------|
| 触摸板 | 手势开始时的鼠标位置 | `PointCapture._touchPadStartPoint = Cursor.Position` |
| 触摸屏 | 手指实际触控位置 | `_pointsCaptured.Values.Select(p => p.FirstOrDefault())` |

因此插件**无需区分设备类型来决定坐标**，直接使用 `PointLocation[0]` 即可。

### 执行流程

```
手势识别完成
  → PluginManager.ExecuteAction()
    → ActivateFocusWindowPlugin.Gestured(pointInfo)
      → Cursor.Position = pointInfo.PointLocation[0]   // 移动光标到目标位置
      → InputSimulator.Mouse.LeftButtonClick()          // 模拟左键点击
      → Thread.Sleep(30)                                // 等待系统处理
```

### 性能

模拟点击方案为 O(1) 操作，无需遍历窗口。

## 实现

### 文件结构

```
GestureSign.CorePlugins/
  ActivateFocusWindow/
    ActivateFocusWindowPlugin.cs   # 插件实现（约 117 行）
```

无配置项，无独立 UI 文件。GUI 属性返回一个 TextBlock 用于显示工作原理说明。

### 关键设计

- **`ActivateWindowDefault = false`**：插件自己负责激活，不依赖 PluginManager 内置的窗口激活机制
- **`Description` 动态返回设备信息**：在 Daemon 执行时，根据 `HostControl.PointCapture.SourceDevice` 返回"触控手指位置"或"鼠标位置"，体现在日志中
- **无序列化**：`Serialize()` 返回空字符串，`Deserialize()` 直接返回 true

### 日志输出

```
# 触摸屏
[PluginManager] Executing: Action=激活焦点窗口 -> 激活焦点窗口（触控手指位置）, ForegroundWindow=...

# 触摸板
[PluginManager] Executing: Action=激活焦点窗口 -> 激活焦点窗口（鼠标位置）, ForegroundWindow=...
```

### 本地化

在 `GestureSign.CorePlugins/Languages/` 的 `zh.xml` 和 `en.xml` 中添加了 `ActivateFocusWindow` 节点，包含：

| Key | 中文 | 英文 |
|-----|------|------|
| Name | 激活焦点窗口 | Activate Focus Window |
| Description | 激活手势起始位置的窗口 | Activate the window at the gesture start position |
| Tip | 工作原理说明（含触摸板/触摸屏区别） | How it works (touchpad/touchscreen difference) |
| TouchPosition | 触控手指位置 | Touch finger position |
| MousePosition | 鼠标位置 | Mouse position |

---

## 使用方式

1. 在 ControlPanel 中为目标应用添加手势动作
2. 将"激活焦点窗口"插件放在动作列表的**第一个**
3. 后续动作（如快捷键）的"激活窗口"选项可取消勾选，避免重复激活
